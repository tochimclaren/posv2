# POSv2

POS stands for "Point of Sale." This version is a minimal, feature-limited adaptation of a Python Django project.

## Functionalities
- Basic authentication  
- Basic CRUD operations  
- Adding and removing items from the cart  
- Automatically converting prices based on the latest exchange rate via SSE  

## Testing
Since TypeScript and Node.js are relatively new to me, my testing capabilities are somewhat limited.  
I have tested endpoints that do not require authentication.
